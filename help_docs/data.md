# Data and exports

## Exporting data
Owners and admins can export bookings, clients and invoices as CSV from
Settings → Data → Export. Exports are emailed as a download link valid for
seven days.

## Where data is stored
Flowdesk stores customer data in the EU (Frankfurt). Backups are encrypted and
kept for 30 days.

## API access
The REST API is available on the Team plan. Create a token under Settings →
API. Tokens are shown once; store them securely.
